# VLESS REALITY и сайт на одном VPS

Установщик для чистой Ubuntu 24.04 x64. Caddy получит сертификат Let's Encrypt и покажет случайный сайт. 3x-ui создаст входящее VLESS REALITY на порту 443 с вашим доменом в SNI. После установки останется добавить клиентов.

## Перед запуском

- Создайте A-запись для своего домена или поддомена. Она должна указывать на публичный IPv4, назначенный интерфейсу VPS
- Для этого имени выключите проксирование CDN и уберите AAAA-запись
- В сетевом фаерволе провайдера разрешите TCP 80, 443 и порт SSH. Оставьте 80 открытым для продления сертификата
- Запускайте на новом сервере. Установщик останавливается, если находит файлы Caddy, 3x-ui или сайта. Вариант с IPv4 за NAT не поддерживается

## Установка

Скачайте `install.sh` на VPS. Проверьте содержимое файла и запустите из своего SSH-сеанса:

```bash
sudo --preserve-env=SSH_CONNECTION bash install.sh
```

Укажите домен без `https://` и пути. Скрипт сверит DNS, установит Caddy, дождётся доверенного сертификата, установит 3x-ui 3.11.0 и создаст входящее. В UFW будут разрешены SSH, HTTP и HTTPS. Если скрипт запущен через консоль без SSH, он считает портом SSH TCP 22.

Скрипт сам выбирает шаблон из [GFW4Fun/randomfakehtml](https://github.com/GFW4Fun/randomfakehtml) и сохраняет его в `/srv/www`. Если скачать шаблон не получится, на домене будет простая страница «Мой сайт». Шаблоны могут содержать сторонние ссылки и скрипты.

В конце скрипт покажет команду для SSH-туннеля, адрес панели, логин и пароль. Выполните команду на компьютере и оставьте окно открытым. Затем откройте адрес панели в браузере. Установщик 3x-ui сохраняет данные входа в `/etc/x-ui/install-result.env` на сервере.

## Добавить клиента

- В 3x-ui откройте «Клиенты» и нажмите «Добавить клиентов»
- Привяжите клиента к входящему `VLESS REALITY`
- На вкладке «Учётные данные» выберите Flow `xtls-rprx-vision` и сохраните
- Импортируйте VLESS-ссылку или QR-код в приложение. В ссылке должен быть ваш домен и порт 443

Откройте свой сайт без VPN. Затем подключите профиль и проверьте внешний IP. Работа VPN зависит от сети, из которой вы подключаетесь.

## Если установка остановилась

Проверьте сообщение в терминале. Причина отказа в сертификате будет в `journalctl -u caddy -n 50 --no-pager`. Журнал установки панели лежит в `/root/reality-setup-x-ui.log` и может содержать данные входа. Не публикуйте его целиком.

После частичной установки скрипт повторно не запускается. Исправьте сбой на месте или начните заново на чистом сервере.
